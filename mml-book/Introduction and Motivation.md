# Data	
- 机器学习内在就是数据驱动的。数据是机器学习的核心
- 机器学习的目标是设计通用方法从数据中提取有价值的范式
# Model
- 为了实现这个目标，设计一个模型通常与数据生成过程相关，类似于数据是由我们提供
- 一个好的模型可以用来预测现实世界会发生什么，而无需进行现实世界的实验。
# Learning
- 学习就是通过优化模型参数自动的从数据中提取范式或结构的方式
# Vector
- 向量的三种解释角度
	- 一组数字的集合（计算机科学角度）
	- 带有方向和大小的矢量（物理角度）
	- 作为矢量对象遵循加法和缩放（数学角度）

# 机器学习的主要观点
- 我们把数据都表示成向量形式
- 选择合适的模型，无论是概率模型还是优化模型
- 我们使用数值优化方法从可用的数据上学习，目的是模型能在未用来训练的数据上也能表现良好
